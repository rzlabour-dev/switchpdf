# SwitchPDF - Professional PDF Tools

A comprehensive suite of PDF manipulation tools that work entirely in your browser. No file uploads to external servers required - maximum privacy and security.

## 🌐 Available Domains

- **switchpdf.io** (Primary)
- **switchpdf.info**
- **switchpdf.one**
- **switchpdf.online**

## 🚀 Features

### Core Tools
- **PDF to Images**: Convert PDF files to JPG, PNG, or WebP images
- **Images to PDF**: Combine multiple images into a single PDF document
- **PDF Merger**: Combine multiple PDF files into one document
- **PDF Splitter**: Split PDF files into multiple documents
- **PDF Compressor**: Reduce PDF file size while maintaining quality
- **PDF Rotator**: Rotate PDF pages to correct orientation
- **PDF Watermark**: Add text or image watermarks to PDFs

### Advanced Tools
- **PDF Password Remover**: Remove password protection from PDFs
- **PDF Text Extractor**: Extract text content in multiple formats (text, HTML, JSON)
- **PDF Page Remover**: Remove specific pages or page ranges
- **PDF Metadata Editor**: View and edit PDF metadata (title, author, etc.)
- **PDF Unlock**: Remove PDF restrictions (printing, copying permissions)

### User Experience
- **Privacy Focused**: All processing happens locally in your browser
- **Smart Export**: Intelligent file naming and format selection
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Professional Branding**: Clean, modern SwitchPDF branding across all domains
- **Sidebar Navigation**: Organized, collapsible navigation menu
- **Tool Switch**: Quick toggle between PDF to Images and Images to PDF

## 🛡️ Privacy & Security

- **Zero Uploads**: Files never leave your device
- **Local Processing**: All operations happen in your browser
- **No External APIs**: No third-party services or tracking
- **Open Source**: Transparent, auditable code

## 📱 How to Use

1. Open any SwitchPDF domain in your modern web browser
2. Choose your desired tool from the sidebar or home page
3. Drag & drop files or click to browse
4. Configure options as needed
5. Process and download your files

## 🌐 Multi-Domain Deployment

This project supports deployment across multiple domains with automatic domain detection:

- **Domain Configuration**: `js/domain-config.js` automatically detects the current domain
- **Dynamic Meta Tags**: Titles, descriptions, and social tags update based on domain
- **Canonical URLs**: Each domain sets its own canonical URLs to prevent duplicate content issues
- **SEO Optimization**: Domain-specific sitemaps and robots.txt files

See `DEPLOYMENT-GUIDE.md` for detailed multi-domain setup instructions.

## 🏗️ Project Structure

## SEO canonical domain

`https://switchpdf.io` is the only canonical/indexable site. Secondary SwitchPDF domains should permanently redirect to `switchpdf.io` and should not publish duplicate site copies or separate sitemaps.
